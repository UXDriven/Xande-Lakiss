# Xande Lakiss — Athletic Performance

Landing page institucional da identidade **FORWARD MOTION**.

## Stack

HTML, CSS e JavaScript puros. Sem dependências, bundler ou processo de build. A Vercel publica os arquivos diretamente da raiz do repositório.

## Experiência

- Hero cinematográfica com fotografia editorial e entrada tipográfica.
- Navegação sticky, progresso de leitura e menu mobile.
- Microinterações e revelações no scroll, com opção de reduzir os movimentos.
- Método interativo com SPEED, POWER e MOBILITY.
- Formulário de intenção que **prepara uma mensagem localmente**, sem enviar dados a terceiros.
- Layout responsivo e controles acessíveis por teclado.

## Identidade

Carbon Black `#101112`, Graphite `#282B2D`, Off White `#F3F1EC`, Silver `#A6AAAC` e Purple `#8B5CF6`. Os arquivos de logo são da identidade Xande Lakiss.

## Para conectar o formulário

O projeto não define um WhatsApp, e-mail ou CRM oficial. Configure o destino de contato e um endpoint de consentimento antes de tratar o formulário como captação de leads. As imagens de atletas são ilustrativas e não representam necessariamente o próprio Xande.
